# pairwise-tessellation

角色走近高模雕塑，轮廓边缘突然裂开，置换贴图把三角形拉出缝隙：曲面细分按固定因子细分，相机距离和屏幕误差没有参与；置换贴图采样在 UV 接缝处不连续，边缘裂开；法线贴图和置换贴图用了不同 UV 集，凹凸方向错；细分后的三角形绕序没有继承，背面剔除把正面剔掉；阴影 pass 用低细分因子，投影和主体轮廓对不上；多 LOD 之间细分因子跳变，切换时顶点弹跳；置换幅度没有按模型缩放，缩放后表面过鼓；UV 边界没有做水密处理，接缝处出现 T 形裂缝；曲面细分和骨骼蒙皮顺序反了，变形后置换错位；移动端细分上限低，和 PC 轮廓差一截；细分因子在帧末统一算，快速推拉镜头时滞后；细分后的包围盒没重算，视锥剔除误杀；细分缓存只按网格 ID，换材质后仍用旧置换。render/tessellation.py 是核心，tests/test_tessellation.py 15个红。要修的是：屏幕误差因子；UV 接缝；UV 集统一；绕序继承；阴影因子；LOD 过渡；缩放幅度；水密边界；蒙皮顺序；平台上限；逐帧因子；包围盒重算；缓存版本。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
